# Poké Auto Idle para Windows

[Baixar o instalador da versão mais recente](https://github.com/DigolaZattera/poke-auto-idle-downloads/releases/latest/download/PokeAutoIdle-Setup.exe)

Abra o instalador no Windows x64. Na primeira abertura, entre com o usuário e a senha do Poké Auto Idle fornecidos pelo administrador. Em seguida, conecte suas próprias contas do jogo e da Kick.

Use **Atualizações**, no rodapé, para consultar as notas da versão. Quando houver uma versão nova, o painel oferece a opção de atualizar e reabrir.
